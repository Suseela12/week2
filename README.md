# Experiment: Prompt Engineering

## Aim
To demonstrate how prompt engineering improves the quality of responses generated by a Large Language Model (LLM) by comparing a baseline prompt with an enhanced prompt.

## Problem Statement
To write a Python program that sends two prompts to the same LLM, captures the responses, and compares their clarity, specificity, and readability.

## Technologies Used
- Python
- Large Language Model (LLM)
- OpenAI API or the same LLM API used in Experiment 1

## Description
This experiment compares two prompting techniques:

1. **Baseline Prompt:** A simple prompt that asks the model to perform a task.
2. **Enhanced Prompt:** A prompt that includes a specific role, context, constraints, and output format.

Both prompts use the same model and parameters to ensure a fair comparison.

## Algorithm / Procedure
1. Connect to the LLM using the API configuration from Experiment 1.
2. Define a function to send prompts and receive responses.
3. Create a baseline prompt.
4. Create an enhanced prompt for the same task.
5. Send both prompts to the LLM.
6. Display both prompts and their responses.
7. Compare the outputs based on clarity, correctness, and readability.

## Example Prompts

**Baseline Prompt:**
```text
What is recursion?
```

**Enhanced Prompt:**
```text
You are a computer science professor.
Explain recursion to a beginner using a real-world analogy.
Keep the explanation to exactly three sentences.
```

## Expected Output
The program displays:
- The baseline prompt and its response.
- The enhanced prompt and its response.
- A brief comparison of the two outputs.

## Result
The experiment demonstrates that enhanced prompts can produce more specific, structured, and beginner-friendly responses by providing clear instructions to the LLM.

## Conclusion
Prompt engineering helps improve the usefulness and readability of LLM responses. Adding a role, constraints, and output-format instructions can guide the model toward the desired response.
